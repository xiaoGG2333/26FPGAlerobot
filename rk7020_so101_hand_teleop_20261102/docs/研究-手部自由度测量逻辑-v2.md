# 手部自由度测量逻辑 v2（2026-10-17，主人定义）

## 一、前提姿势
1. 小臂方向与相机光轴**平行反向共线**（小臂指向镜头，手指指向屏幕里）
2. 初始虎口朝上
3. 爪头**指向**由手掌方向（手指方向）决定
4. 爪头**自转**由虎口朝向决定

以右手为例：虎口向上、手掌朝向左前方；小臂顺时针旋转 → 虎口顺时针转、爪头指向不变、爪头自转；保持虎口朝上把小臂往里收 → 爪头平移但不自转。

## 二、手部坐标系（world landmarks，实测轴向：y 向下、z 指向场景内）

| 记号 | 定义 | 用途 |
|---|---|---|
| `P` | 掌心 = mean(p0,p5,p9,p13,p17) | 位置 |
| `T` | 腕→中指根 = w9 − w0（小臂延续方向） | 爪头指向 |
| `G` | 虎口侧 = 食指根 − 小指根 = w5 − w17 | 爪头自转参考 |
| 上 | `UP = (0,−1,0)` | 参考方向 |

## 三、三个观测量

```
point  = asin( T · UP )                                   # 爪头仰角：0=水平前指，+90=指天
cuff3d = 虎口 G 绕 T 相对"上"的转角（全量程 ±180，右手定则）
cuff2d = atan2( d.x , −d.y )，d = p5 − p17（图像坐标）      # 画面内虎口方位：0=虎口朝上
```

- `point`、`cuff3d` 用 3D（world）→ 通用，但吃深度噪声
- `cuff2d` 只用图像点 → 在本姿势下与 `cuff3d` 近似等价，且**完全不吃深度噪声**（默认用它）

## 四、映射到 5 轴臂

| 主人规则 | 观测量 | 机械臂自由度 |
|---|---|---|
| 手的位置 | 掌心 (u,v) | x, y（z 固定） |
| 爪头指向 | `point`（仰角） | **pitch** = ID4 wrist_flex |
| 爪头自转 | `cuff2d`（或 `cuff3d`） | **roll** = ID5 wrist_roll |
| — | 由位置反算 | yaw = ID1 |

换算仍是统一的：
```
roll  = roll0  + sign·gain·deadzone(cuff − cuff0, 4°)
pitch = pitch0 + sign·gain·deadzone(point − point0, 3°)   （先软限 ±0.85，再硬夹 ±1.4）
```
零位 `cuff0 / point0` 在按 `c` 时记录。

### 用例子自检
- **小臂绕自身轴转**：`T` 不变 → `point` 不变 → pitch 不动；`G` 转 → `cuff` 变 → roll 转。✓ 与"爪转、指向不变"一致
- **保持虎口朝上、小臂内收**：只有 `P` 变 → 只有 x,y 变；`T`、`G` 方向都不变 → roll/pitch 完全不动。✓
- **翻手掌（掌心↔手背）**：`cuff` 走 ±180 全量程，能区分正反面（旧的 α 方案在 ±90 处有奇点，所以分不出来）

## 五、必须说明的一处牺牲
5 轴臂的"爪头指向"只有**仰角**能由手决定，**方位角（左右偏）给不了**：3 个位置轴 + yaw 已经把"从肩膀指向目标"的水平方位占满，yaw 必须跟随位置反算（否则目标位形不在可达流形上，IK 会解不出/跑满迭代）。
→ 想要"手能左右摆爪头"，要么 6 轴，要么牺牲位置跟随。

## 六、可切换的源（`t` / `u` 键）
- roll：`cuff2d`（默认）→ `cuff`(3D) → `palm`（掌心朝向 α）→ `twist`（绕臂轴）
- pitch：`point`（默认）→ `v`（掌心纵向位置）→ `phi`（法线倾角）

# 最终定案（2026-10-17 晚，主人拍板）

控制逻辑收成三条，pitch 不再由手给：

| 手部观测 | 机械臂 | 公式 |
|---|---|---|
| 掌心横向 u | **y 左右** | y = y0 + sign_u·gain_y·dz(u−u0)，gain_y=0.6，dz=0.008 |
| 掌心纵向 v | **z 上下** | z = z0 − sign_v·gain_z_v·dz(v−v0)，gain_z_v=0.6，dz=0.008 |
| 手的大小（腕→中指根像素长） | **x 前后** | x = x0 + sign_size·gain_x_size·(−dz(手长比−1))，手长比=hp0/hp，gain=0.5，dz=0.02 |
| 画面内腕转角 theta | **roll** | roll = roll0 + sign·gain·dz(theta−theta0)，gain=1.0(现场存 2.0)，dz=4° |
| 伸指数 5/0 | **夹爪** | 5→1.0，0→0.0，其它保持 |
| 位置反算 | **yaw** | atan2(y, x−0.0612) |
| — | pitch ID4 | **固定 hold**，保持起始 −0.0977 rad |

- 手长基准 `hand_px0` 在按 `c` 时记录；缺失时自动用第一帧有手的手长补上并打印提示
- 物理含义：手比标定时大 20% → 手长比 0.833 → 往前 ≈ 8.3 cm（gain_x_size≈假定标定距离 0.5 m）
- 方向翻转键：`y` 左右、`v` 上下、`z` 前后、`x` roll、`p` pitch
- 死区/限速/夹紧不变：0.8% 死区、0.02 m/s 平移限速、0.15 rad/s 旋转限速、工作空间 ∩ 固件硬限

# 手势自动标定（2026-10-31）

演示前不必回电脑按键，**快速握拳 2 次 → 张开手掌**即自动重采零位。

- 触发判定：`伸指数 ≤ 1`（握下）出现 2 次，间隔 ≤ `window_s`（默认 1.2 s）
- 采零位时机：第 2 次握拳后**等待手掌张开**（`伸指数 ≥ 4`），取 `average_frames`（默认 5）帧平均
  —— 用张开手采，`hand_px0`（前后基准）与 u/v 才是演示用的自然姿势
- 冷却 `cooldown_s`（2.5 s）防连触发；等张开超时 `open_wait_s`（4 s）则放弃并提示
- 生效后屏幕顶部绿色横幅提示，日志打印 `[自动标定] 零位已更新 ...`；不影响 `c` 手动采零位
- 参数在 `calib.json → auto_zero`：`enable / grasps / window_s / open_wait_s / average_frames / cooldown_s`
