# W1 D1 板上联调前置 · 操作说明

> 目标:拿到 ID1-5 只读基线(位置/电压/温度/负载,重点 ID2)与板上 IK 单解耗时基线。
> 工具: `sw/diag/run_w1_d1.py`(本工程自建,链路与协议沿用原仓库 26FPGAlerobot,固件**不改**)

## 0. 前置条件

1. 机械臂电源、舵机总线、Zynq 板(装**最新包** BOOT.BIN 的 SD 卡)按原仓库接线接好:
   - 电脑 USB 转 TTL ↔ Zynq UART0 调试串口(115200 8N1)
   - Zynq UART1(W12 TX / V12 RX,LVCMOS33) ↔ 舵机总线
2. 串口在 Windows 设备管理器中确认 COM 号(如 COM16)。
3. 依赖:`pip install pyserial`(见 `sw/diag/requirements.txt`)。
4. **断电状态下接任何新硬件**(红线 5)。上电后等固件 READY。

## 1. 运行

```bash
cd sw/diag
python run_w1_d1.py --port COM16 --samples 20 --ik-probe --probe-count 12
```

- `--samples 20`:静止反馈采样轮数(ID2 漂移基线需要足够轮数,建议 ≥20)
- `--ik-probe`:无运动 IK 求解计时(目标 = 当前位姿 ±2mm,不驱动机械臂)
- 全程无运动命令、无扭矩使能、无 EEPROM 写(工具 docstring 与固件 CAL1 链路保证)

## 2. 判定标准

| 项 | 通过标准 | 不通过时 |
|---|---|---|
| 静止诊断 | 全 ID 电压 9~12.6V、温度 ≤55℃、扭矩为 0、位置在限位内 | 查供电/接线/舵机健康,记录后停 |
| ID2 漂移基线 | 记录 min/max/漂移计数(历史漂移 2003→2021,18 计数) | 正常记录即可,这是"基线"不是判定 |
| IK 单解耗时 | 往返中位数 − 串口开销(~15ms) < 5ms | 用 `fpga/diag_fw/` 精确打点复核 |

## 3. 结果

输出到 `results/w1_diagnostics/<时间戳>/`:
- `static/summary.json` — 逐样本原始反馈(ID1-6)
- `w1_d1_summary.json` — 汇总 + ID2 漂移统计 + IK 计时
- 红线 7:一切实测数据落 `results/` 并注明条件,不引用历史数字冒充新验证

## 4. 其他可用工具(原仓库链路,保持只读用法)

- `python diagnose_teleop.py --port COM16 --probe-ik` — 遥测 + 无运动 IK probe(原版)
- `python diagnose_usb_feedback.py --port COM12` — USB 直连舵机总线的只读温度交叉核对(不走 Zynq)
