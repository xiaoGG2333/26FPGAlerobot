# 2025.2 独立迁移说明

## 范围

本目录是独立迁移版本，父目录中的旧工程只读。保留当前 HLS/ARM 算法、迭代、双核地址、轨迹、编码器映射与限位、Xbox 方向及速度、ID6 夹爪、温控、扭矩和错误处理策略。迁移只调整工程创建及工具适配。

工具安装版本为 Vivado/Vitis 2025.2；硬件为 xc7z100ffg900-2，PL 125 MHz。third_party 中的 Vitis_Libraries_2024.2 是固定版本的源代码依赖，不是调用旧工具或复用旧 IP。

## 环境与构建

当前验证目标为 Windows。安装 Vivado/Vitis 2025.2 及 Zynq-7000 器件支持，并具备目标器件所需许可证。准备 Python 3；主构建脚本只使用 Python 标准库。Vitis 平台脚本由工具自带 Python 执行。可选的软件回归另需 native GCC。

1. 修改 config/toolchain.json 中 amd_root 和 native_gcc，指向本机安装位置。
2. 在本目录运行：`python scripts/build_all.py`。
3. 构建链：源码一致性 → 工具版本 → C 仿真 → HLS 综合 → RTL 协同仿真 → IP 打包 → 寄存器兼容性 → Vivado 新建工程/综合/实现 → 新建平台/BSP/FSBL → ARM 编译/BOOT 打包。
4. 检查 reports/build_status.json、logs/ 和 build/hardware_export/ 下的时序、资源及 DRC 报告。
5. 额外运行 `python scripts/verify_software.py`、`python scripts/run_opt_native.py`，以及 scripts/run_thermal_sim.ps1、scripts/run_xadc_sim.ps1。

重试可使用 `--from-stage hardware` 等参数，但只有干净目录的完整构建才能作为从零复现证据。干净构建应在源码副本中移除该副本的 build/、logs/ 和 board/boot/ 后进行，不能删除父目录中的旧工程。

## 生成物和安全边界

候选启动文件：board/boot/BOOT.BIN；其中 FSBL、位流、应用均由本次新工具链生成。源程序中的历史固件协议标识保持不变；请用输出 SHA256 清单区分迁移包，不要仅凭 HELLO 字符串判断版本。

构建与离线验证不会打开串口、JTAG 或启用电机。任何失败构建都不能作为上板候选包。实机验证单独进行；未通过前，旧版仍是正式回退基线。

## 实机验收顺序

1. 保留旧 SD 启动文件并记录其校验值。
2. 使用新启动文件启动，先通过只读命令检查串口、芯片温度、风扇和六轴反馈。
3. 不启用运动，验证 FPGA 单步、完整迭代及错误处理。
4. 在现场条件确认后测试 Xbox 五轴协调、松杆完成目标、ID6 独立开合、停止和扭矩策略。
5. 温控和通信故障优先用仿真或受控故障注入验证，不能通过故意过热测试。
6. 保存串口日志、CSV、板端结果与实际观察；全部通过后才能将后续工作切换至本版本。

## 比赛材料边界

本迁移目录解决工具版本及复现问题。完整满足 3.3 的提交仍需正式设计报告、性能与资源对照、真实板端验证、大模型协作记录和可复用 Skill 包。迁移本身不等于已经获得性能提升，也不替代上述材料。

## 本次迁移验证结果（2026-11-01）

2025.2 HLS 仿真/综合/IP 打包、Vivado 从零创建/综合/实现、全新 Vitis 平台/BSP/FSBL、ARM 固件编译和 Bootgen 已通过。125 MHz 最终导出报告 WNS +0.382 ns、WHS +0.024 ns。LUT 32718（11.79%）、FF 38263（6.90%）、DSP 190（9.41%）、BRAM 4（0.53%）。

63 个运行源码及引脚约束文件与旧版一致；第三方依赖源码一致；PS 参数、端口、连接、地址分配、61 项寄存器定义及 ARM 定时器配置均已核对。649 个 RTL 协同仿真事务、1878 个软件逆解对比和 29 项主机协议测试通过，其他控制/夹爪/温控回归见 reports/。

本次没有进行实机验收，没有更新 SD 或虚拟机，没有启用机械臂运动。新版本为候选版本，旧版仍保留为正式回退基线。资源与时序变化来自工具实现差异，不表示算法功能改动，也不作为计算加速结论。

## 累计迭代数协议修复

主机旧解析器将迭代次数限制为200，不能兼容备用初值的累计次数。现根据 HELLO 的 BOUND_RETRY_IK_20261031_V1 标识将上限设为200+80+80=360；旧固件仍为200。仅修改 host/right_joycon.py，不改变ARM/PL、目标拒绝、扭矩或舵机行为。固件BOOT.BIN无需更换。原63个文件中62个仍与迁移基线一致，该主机兼容适配记录于 manifests/migration_compatibility_sha256.json。
