## 1. 项目概述

**一句话目标**:在 RIGUKE RK-ZYNQ7020(Zynq 7020)上部署摄像头手部检测,操作者手掌在画面中的位置经坐标映射与逆解,实时驱动 SO-101 机械臂末端跟随——"隔空拖拽"式体感遥操作,夹爪随握拳/张开二值开合。

| 项 | 值 |
|---|---|
| 交付物 | 比赛演示系统:手掌移动→机械臂跟随;握拳→夹爪闭合,张开→夹爪张开 |
| Deadline | 自 2026-10-13 起 1 个月内比赛演示,不可延期 |
| 性能指标 | 视觉 30fps(PL 版目标)/ 15fps(A9 保命版底线);控制环 30Hz;端到端感知延迟目标 ≤200ms(PL 版) |
| 演示环境 | 室内可控光照,单人操作,距相机 1-2m,正对相机 |
| 安全要求 | 物理急停按键,触发后立即释放舵机力矩 |

**弃用方案(已论证,勿重做)**:
- ❌ 手臂姿态镜像(肩肘腕关节角映射)——演示叙事与复用度均不如手部方案,已弃
- ❌ DPU/Vitis AI 跑模型——Vitis AI 自 1.4 起停止支持 Zynq-7000(Xilinx 官方答复 #76742),且与工程使用的 2024.2 工具链冲突;最小 B512 需 118 DSP 而现有工程已占 198/220
- ❌ 散热/DDR 带宽优化——主人明确不在考虑范围
- ❌ 21 关键点手部回归——用"手掌检测 + 拳/开二分类"替代,难度大幅降低;腕转关节固定角度(见第 10 节未决项)

### 2.4 控制栈既有逻辑(移植时保持语义)

- 舵机总线:**PL 引脚 UART1,W12 TX / V12 RX,LVCMOS33**,非 USB。协议 STS3215,五轴同步用 `0x83 SYNC_WRITE` 单帧下发
- 温度保护:单轴 >55℃ 持续 >1500ms 才停机并关力矩;读失败按通信故障冻结处理
- 到位判定:目标误差 ≤8 计数且连续 3 次采样;轮询间隔 80ms;到位后不发 STOP、不关扭矩
- 故障策略:通信/心跳(500ms)/健康故障→冻结新目标、保留最后目标与力矩;超温/急停/启动失败→关力矩并读回确认(`off_confirmed`)
- 同步速度参数:100~600,最大行程轴 600,其余按比例(最低 100)
- **已知问题**:ID2(shoulder_lift)历史有保持漂移(目标 2003 漂到 2021);不可达目标点不收敛(见第 8 节风险);最新包实物运动未验收,联调第一天优先做只读反馈诊断(ID1-5 位置/电压/温度/负载)

## 3. 系统架构

```
[OV7725/OV5640 DVP] → [PL: 采集时序 + VDMA] → DDR 帧缓存
        → [推理模块 hand_infer]  ← 本项目唯一可替换模块
              A9 版:NCNN INT8(第 1 周起,持续保留)
              PL 版:自研 HLS 加速器(第 2-4 周,热替换)
        → [坐标映射 + 工作空间限幅 + EMA]        (A9)
        → [IK 目标点] → [ARM FK 迭代 ⇄ PL 逆解核] (A9 ⇄ PL)
        → [arm_control 舵机栈] → [UART1] → [SO-101 ×6 STS3215]
[物理急停按键] → GPIO 中断 → 释放力矩
```

**计算分工原则(主人明确要求)**:尽可能多放 PL。最终形态中 PL 承担:图像采集、resize 预处理、CNN 推理(检测+分类)、逆解;A9 只留:IK 迭代驱动、串口收发、健康监控、坐标映射与滤波(几何运算轻量,可后评估是否下放 PL)。

**帧管理**:高帧率摄像头的价值是"永远取最新帧"——采集 60fps、推理消费 30fps,积压帧直接丢弃,压端到端延迟。禁止排队处理旧帧。

## 4. 推理模块接口契约(两版实现必须共同遵守)

```c
typedef struct {
    float u, v;        // 手掌中心在原始画面中的像素坐标
    float confidence;  // 检测置信度 0~1,低于阈值视为"手丢失"
    bool  fist;        // true=握拳(夹爪闭), false=张开(夹爪开)
} HandResult;

// 唯一对外接口。实现可替换,签名永不变
HandResult hand_infer(const Frame* frame);
```

- `Frame`:DDR 中的最新帧(格式/分辨率由采集通路定义,W1 钉死后写入本文档附录)
- 手丢失(连续 N 帧 confidence 低于阈值,N≥5):目标冻结、夹爪保持,恢复后经滞回再跟随
- 推理耗时预算:A9 版单帧 ≤66ms(15fps 底线,力争 ≤33ms),PL 版 ≤10ms(30fps 目标)

**网络结构要求(HLS 化前置约束,第 1 周选型时必须满足并在 PC 验证后冻结)**:
- 全卷积,无全连接层的大矩阵乘
- 静态输入 shape,固定输出尺寸
- 无动态控制流(数据依赖的 if/while)、无 NMS 后处理(输出直接回归框/中心点)
- 算子白名单:conv / depthwise-conv / pooling / ReLU / 硬核 sigmoid / elementwise add
- INT8 量化感知训练(QAT),PC 浮点模型为精度基准
- **总 MACs 硬预算**:A9 版 ≤30M,PL 版 ≤60M(@256×256 等效输入);换板后 PL 版预算可放宽,但网络结构仍以 W1 冻结版为准

**模型形态**:两小模型——① 手掌检测(全图,输入 ≤256×256,输出手掌 bbox/中心);② 拳/开二分类(ROI 128×128)。第 N 帧检测、第 N+1 帧分类的帧间乒乓流水(PL 版);A9 版顺序执行即可。

## 5. 坐标映射与控制环

1. **标定**(一次性,程序带引导):机械爪走到工作空间 2~4 个已知点,操作者把手放在"希望爪到该处"的画面位置,记录 (u,v)↔(x,y) 点对,解每轴仿射(缩放+偏移)。相机三脚架固定,标定后**不得移动相机**
2. **深度**:固定深度平面方案,z 常数(标定参数之一)。手掌画面尺寸不做深度估计(明确弃用,噪声大)
3. **限幅**:视觉目标点钳制在标定安全盒内 + 滞回(出界贴边保持);此为强制项,防 IK 不收敛
4. **滤波**:EMA 平滑(α 初值 0.4)+ 死区(目标变化 <5px 不更新)
5. **30Hz 控制环**:取最新 HandResult → 映射 → 限幅 → IK 解算(初值用上一解热启动;目标不变则跳过重解)→ 插值下发 SYNC_WRITE。IK 单解 15~34 次迭代,板上本地调用预计 <1ms(历史 19.5~35.2ms 含 Ubuntu 主机串口往返,不可比),W1 首日实测验证
6. **夹爪**:ID6,fist 状态经 3 帧多数表决后切换,全开/全闭两个预设位
7. **腕转(ID5)**:固定中间位(计数值约 2037 附近的安全姿态),不参与跟随

## 6. 四周里程碑(每项含验收标准)

### 第 1 周:A9 版全链路跑通(保命周,结束时系统必须可演示)

| 天 | 任务 | 验收标准 |
|---|---|---|
| D1 | 板上联调前置:只读诊断 ID1-5(位置/电压/温度/负载),重点盯 ID2;实测板上 IK 单解耗时 | 拿到基线数据,IK 单解 <5ms 即视为通过 |
| D1-2 | PC 模型选型+训练+量化:手掌检测 + 拳/开分类,结构满足第 4 节约束;录演示场景视频离线验证 | 拳/开准确率 ≥90%;手掌中心抖动 ≤8px;输出《网络结构清单》(逐层算子/shape/量化方式),**冻结** |
| D2-3 | 视觉版 bitstream v1:基于厂家采集例程,DVP→VDMA→DDR,单逆解核;PetaLinux 出启动镜像 | Linux 下 30fps 读到帧,`v4l2`/mmap 可取,帧序单调 |
| D3-4 | NCNN 交叉编译上板,实现 `hand_infer`(A9 版);移植 ARM FK 迭代(mmap /dev/mem 访问 0x40000000)+ arm_control(ttyPS1) | 板上推理 ≥15fps;IK 核被正确调用并收敛 |
| D4-5 | 标定 + 限幅 + EMA + 30Hz 控制环 + 急停按键接 GPIO | **端到端演示:挥手→臂跟随,握拳→爪闭,急停→力矩立即释放** |

**W1 保命策略顺序(A9 推理不达标时依次启用,不得跳级)**:① 换更小网络 → ② 降输入分辨率(检测 256→160→128,分类 128→96) → ③ 帧率降 10~15fps(最后手段,影响跟随体验,启用前须汇报主人)。每级启用后重新跑 PC 精度验证(拳/开 ≥90%、中心抖动 ≤8px)。

### 第 2 周:HLS 引擎 + A9 版打磨(并行双线)

- 线 1(HLS):conv 引擎 HLS IP 详细设计(DDR 权重加载、乒乓缓冲、固定循环边界)→ 前几层实现 + C 仿真;同步做 QAT 精度补偿
  - 验收:PC 上定点仿真 vs 浮点,逐层最大绝对误差在预算内(预算表随结构清单建立)
- 线 2(A9 版):鲁棒性(光照/背景/快速挥动)、限幅边界实测、ID2 漂移观察、延迟统计
  - 验收:连续运行 30 分钟无故障冻结;端到端延迟报告

### 第 3 周:HLS 集成

- 全网络 C 仿真跑通 → RTL 协仿 → 时序收敛(FCLK 100MHz 或按需降频)→ 封 AXI IP,与单逆解核同 bitstream
- 验收:板上 PL 推理结果与 C 仿真一致;检测+分类流水 ≥30fps

### 第 4 周:热替换 + 彩排

- `hand_infer` 切换 PL 后端(签名不变);全系统延迟复测;演示彩排 ≥3 遍完整流程
- 产出三张可启动 SD 卡:**PL 版(主)、A9 版(备)、Xbox 裸机版(兜底,原仓库原样)**
- 验收:彩排通过;三张卡均可冷启动进入工作状态
