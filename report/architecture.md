# 架构与版本范围

- 电脑Ubuntu：Xbox输入、目标转换、串口协议、日志。当前手势识别未实现验收。
- PS裸机：FK与误差、完整迭代与备用初值、终点检查、在线五轴轨迹、舵机总线、故障状态。
- PL：雅可比/正规方程/单步LM求解；125MHz；双IP地址0x40000000/0x40010000。完整迭代没有下沉PL。
- UART0：电脑调试与目标协议；UART1：舵机适配器总线。端口号由实际枚举确定，不能固定认为COM16或ttyUSB1永远正确。
- XYZ端点为模型腕旋转轴参考点；XYZ+ID5任务放开俯仰，不是完整六维姿态任务，也不是夹爪尖端定位。
- ID6独立夹爪，LT关闭、RT开启、同时按下或松开保持开度。不能把ID6混入五轴IK。

运行语义：普通目标拒绝保留上一有效目标、撤销主机未执行累计；正常运行通信异常/心跳丢失冻结新目标并保持扭矩；显式STOP、退出、启动无有效保持目标与舵机温度异常按原策略处理。芯片温控与舵机温控策略不同，以实际代码为准。

版本快照（不是自动选择部署版本）：
1. 根目录bound_retry：2024.2，BOUND_RETRY_IK_20261031_V1；原LM先算，失败后最多两组备用种子，各80迭代，共600硬件调用预算。
2. repro_2025_2：独立2025.2候选目录，具有完整构建阶段；migration_validation明确formal_baseline_switched=false，board_execution=NOT_RUN。主机协议还有按HELLO能力区分迭代计数字段上限的兼容修正，不能笼统声称整个目录逐字不变。

不得把两版的资源、时序、BOOT或测试结论混在一张没有版本标注的表中。
