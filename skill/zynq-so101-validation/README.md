## 使用

人工阅读从SKILL.md开始；支持本地Skill的工具可将整个zynq-so101-validation目录安装到其技能目录后调用 `$zynq-so101-validation`。本次只生成项目内技能包，未修改个人全局技能配置。

请求示例：
- “使用这个Skill分析运行日志：目标在变化，实际计数不动；先不驱动。”
- “检查2025.2候选发布的构建证据，并列出尚未完成的板端验收。”
- “只修改逆解策略，证明舵机控制、映射与温控文件未变化。”

## 已有经验与效果

已整理构建配套、分层诊断、映射核验、优化回归和虚拟机环境处理流程。1878例离线对照无原成功案例回退，7例合成目标被备用求解救回；这些是工程报告记录，不是本Skill使实物成功率提高的实验证明。2024.2基线和2025.2候选均有离线/构建报告，报告中的board_execution仍为NOT_RUN。详见references/evidence.md。

## 适用范围与失败条件

适用于同类PS迭代+PL单步求解、串口控制的工程。换机器人、安装方式、工具点或协议时，必须重新确认模型和接口。没有准确初值/目标或缺少总线反馈的日志，不能唯一确定失败原因。当前参考姿态绝对精度未认证。手势识别和视觉抓取仅为扩展设想。

## 本技能包的验证

check_evidence.py检查参考文件的存在性和SHA256，并回显报告里的验证层级。脚本测试涵盖文件缺失、篡改、无效JSON和目录越界；不会执行运动。技能格式与本地引用另做检查。此包尚无独立用户实物复用验收，不声称已完成。
