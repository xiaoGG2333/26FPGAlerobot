# 编码器、模型参考与限位

以firmware/servo_mapping.h为当前事实来源，使用count=zero+sign*q*651.8986469044033，逆变换q=sign*(count-zero)/counts_per_rad。q为弧度。Present_Position已包含舵机Homing_Offset调整，不再次相加。

零点快照：ID1..5分别2121、2156、1893、1986、2037；方向-、+、+、+、-。原始范围分别1164..2964、828..3197、876..3073、874..3180、170..3966；这是本机测量数据，不能推广到其他装配。命令角度边界包含10计数余量。q_to_counts自身的raw范围检查与上游命令余量应分别读源码确认。

## 核验方法

1. 保留官方参数与舵机当前设置；不要为了查看编码器写EEPROM。
2. 将已知实体参考姿态与同一时刻的编码器样本配对。照片不能精确认证角度。
3. 单关节手动改变方向，比较多次采样，同时查看其他轴变化；若其他轴明显移动，不能把末端运动简单归因单轴。
4. 按实物参考回位并复测；编码器自动回到旧数只能验证计数复现，不能独立证明模型零位正确。
5. 限位采样标记安装条件。桌面或固定件形成的边界应标注为该安装下的可用行程，不能当作舵机机械极限。
6. 检查角度/计数互转、端点余量、整组原子拒绝与非有限数。修改范围不等于应该修改零点、方向或几何尺寸。

当前SO101_PHYSICAL_ALIGNMENT_VERIFIED为0，绝对几何精度仍未认证。该标志不能只因通信测试通过改为1。ID6独立端点见host/gripper_config.json和标定报告，不由五轴限位推导。
